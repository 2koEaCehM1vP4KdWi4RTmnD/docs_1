# Initial Setup & Requirements

Once our Q1 2025 goal is reached, you will be able to jump into BloksimAI with a few straightforward prerequisites:

* **Modern Web Browser**: Chrome, Firefox, or an equivalent for the best user experience.
* **Wallet Compatibility**: A Solana or multi-chain wallet (e.g., Phantom, MetaMask) for safe storage and on-chain interactions.
* **Basic Blockchain Awareness**: While not mandatory, familiarity with cryptocurrencies and decentralized finance can help unlock the platform’s deeper functionalities.

**Fast Track Instructions**

1. **Sign Up / Log In**: Choose a secure authentication method to create your BloksimAI account.
2. **Connect Your Wallet**: Sync your wallet with the BloksimAI interface to start real-time data access.
3. **Explore the Dashboard**: Dive into the main dashboard to discover wallet insights, coin data, and AI agent controls.
